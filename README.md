Este repo contém apenas o build final pronto pra uso — sem código-fonte.

## Como usar

Execute num executor de Roblox. Não requer servidor local:

```lua

```

## Atenção

- Arquivo único, ofuscado (`petrix_hub_mm2_obf.lua`).
- Se o executor falhar ao compilar, use um **executor mais novo** ou que
  suporte scripts grandes (o arquivo tem ~2 MB).
- Ferramentas de ofuscação e execução de scripts em jogos online podem violar
  os Termos de Serviço do Roblox. Use por sua própria conta e risco.
